# PORTRAIT 全量分析模板 v1.0

> 目标格式标准。每份 portrait 应覆盖以下全部章节，按人物类型调整侧重点。

---

## 必须覆盖的章节

### 一、基本信息 + 职业/学术全轨迹（时间线表）
- 出生、学历、关键转折点
- 每个阶段的"核心贡献"——不是职位，是做了什么

### 二、核心思想体系（≥2 个独立概念）
- 每个概念：命名 + 一句话定义 + 为什么重要 + 对 TRIO 的启示
- 国际人物：提取原创理论/方法论
- 中国院士：提取科研范式/工程哲学/学术治理观点

### 三、方法论/工作方式（如有独特之处）
- 教育方法论（如 Karpathy）、管理哲学（如 Boris Cherny）、科研范式
- 没有独特方法论的，写"学术产出特征"：论文数量、领域、合作模式

### 四、TRIO 映射（3-5 条）
- 这个人的思想/方法如何适用于 TRIO 系统
- 格式：原则 | TRIO 适用

### 五、局限与盲点（≥2 条）
- 批判性视角：什么情况下这个人的方法会失效
- 学术人物的"盲点"：学科局限、时代局限、未经验证的假设

### 六、关键决策节点 / 一句话总结
- 3-5 个关键选择及其代价
- 最后一句：这个人的核心遗产是什么

### 七、搜索溯源
- 列出使用的信息来源

---

## 长度标准
- Tier 4→全量: 从 40-60 行扩展到 80-120 行
- Tier 3→全量: 从 25-40 行扩展到 80-120 行
- Tier 2→全量: 从 16-25 行扩展到 80-120 行
- Tier 0-1+缺失: 从零/极少扩展到 80-120 行

## 格式规范
- Markdown，中文撰写
- 表格对齐，代码块标注语言
- 引用用 `>` 标注
- 粗体用于关键概念首次出现
- 关联其他人物用 `[[人名]]` 格式
