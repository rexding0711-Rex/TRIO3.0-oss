# TRIO C0 对照实验 · 30 题设计

> 用途: 测 TRIO harness 的真实增益 + 作为每次改动的回归集
> 日期: 2026-08-11 | 依据: 二轮审计共识 C2(对照实验缺席 → 提前)
> 参与方: 用户(出题/评估)· TRIO 3.0(实验组)· 裸模型(对照组)

---

## 一、实验本质

**测的是系统 harness 增益,不是用户判断力。**

```
同一批 30 题
  ├─ 实验组: 走 /all 全流程(分支路由→三面具→判断包→预测注册) → TRIO 3.0 答
  └─ 对照组: 裸模型直接答(不加载任何 TRIO 框架) → 裸 Claude/DeepSeek 答
        ↓
对比两组输出质量 → 差距 = TRIO harness 增益
```

## 二、核心约束(实验成立的前提)

1. **30 题全部用历史案例**——有已知结果,判得了对错
2. **不包含未来预测**——无法客观评分
3. **两组互不可见**——跑完前互不查看输出
4. **评估盲评**——打分组别随机,避免评估者偏袒
5. **背景资料只给历史时点信息**——防结果泄漏

## 三、题型分布(5 类 × 6 题)

| 类 | 题数 | 判断类型 | 历史案例示例 |
|----|:---:|---------|-------------|
| 投资 | 6 | 择时/估值/风险 | 2024 年英伟达该不该追高(结果:2025 回撤) |
| 产品 | 6 | 需求/定位/取舍 | 某新品类该不该做(结果:市场验证) |
| 工程 | 6 | 技术路线/物理可行性 | 某材料方案能否量产(结果:良率/成本) |
| 商业 | 6 | 竞争/定价/供应链 | 某市场谁赢(结果:份额变化) |
| 战略 | 6 | 趋势/进入/放弃 | 某赛道该不该进(结果:后续事件) |

## 四、出题模板(每题填一份)

```
ID:        I-01(投资) / P-01(产品) / E-01(工程) / B-01(商业) / S-01(战略)
类别:      
难度:      易 / 中 / 难
背景(喂给模型):
   <历史时点的公开信息,只含当时可知,不含结果>
问题:
   <当时要做的判断,一句话>
已知结果:
   <历史实际发生,评估用——不喂给模型>
可证伪:
   <结论能否明确判对错?能/部分>
```

## 五、评估打分表(每组每题)

| 维度 | 分值 | 评分标准 |
|------|:---:|---------|
| 结论正确性 | 5 | vs 已知结果: 命中 5 / 部分命中 2-4 / 错误 0-1 |
| 推理质量 | 2 | 逻辑链完整: 含中间链条 2 / 跳跃 1 / 无推理 0 |
| 反证覆盖 | 2 | 主动找反证: 有且有效 2 / 提到未验证 1 / 无 0 |
| 置信度校准 | 1 | 高置信(≥4)是否真有把握: 合理 1 / 虚高 0 |
| **合计** | **10** | |

## 六、执行流程

1. **出题**: 用户按模板填 30 题(本题表 + 模板)
2. **对照组**: 裸 Claude/DeepSeek 直接答(无 TRIO 框架,温度默认)
3. **实验组**: 走 /all 全流程,每组独立会话
4. **盲评**: 打乱组别 → 用户按打分表评估(只看到结论,不看到组别)
5. **汇总**: 两组平均分 + 分维度对比 → TRIO harness 增益量化
6. **回归复用**: 每次改动(llms.txt/路由/hook)后重跑 30 题,防改坏
7. **外部洞察吸收(2026-08-11 加入)**: 对照组(外部模型)答案返回后,逐条比对外部 vs TRIO 实验组——标记"外部更优且 TRIO 没想到"的洞察(满足: 新颖/可复用/可验证/反直觉),写入 `knowledge/external-insights/absorption-{case}-{日期}.md`;重大洞察回写 CORE.md//all/分支 manifest。**原则: 不是全部吸收,只吸收 TRIO 没想到的。**

## 七、防污染细则

| 项 | 措施 |
|----|------|
| 结果泄漏 | 背景只写历史时点信息,已知结果放单独评估表 |
| 记忆污染 | 对照组用全新会话;实验组清空上下文 |
| 评估偏袒 | 打分组别随机打乱,评估者不知归属 |
| 题目顺序 | 两组用相同顺序,消除顺序效应 |

## 八、预期输出

```
结论: TRIO 全开 平均 X.X/10 vs 裸模型 Y.Y/10,增益 +Z.Z
分维度: 反证覆盖提升最大 / 推理质量提升最小
置信度: 实验组校准度(高置信命中率)是否优于对照组
→ 若增益不显著: 说明 harness 未真正参与推理,回到"接线深度"检查
```

## 九、样例题目(示范怎么填)

```
ID:        I-01
类别:      投资
难度:      中
背景(喂给模型):
   2024 年 3 月,英伟达(NVDA)股价约 $900,市盈率约 70 倍。
   市场信息: AI 数据中心 GPU 需求爆发,供给紧张(H100 交期 36 周);
   云厂商资本开支上调;但市场担忧"估值泡沫",历史上前两轮
   AI 炒作(2018/2021)GPU 股均出现大幅回撤。
问题:      现在该追高买入,还是等待回调?
已知结果:  2024 年内 NVDA 继续大涨(2024/6 拆股后持续走高),
            2025 年 7 月后因 AI 资本开支放缓担忧出现显著回撤。
可证伪:    能——"该追高"或"该等回调"都有明确可判结果。
```

**填题要点**:
- 背景只写"当时可知",绝不写结果
- 难度要混合(易/中/难各占 1/3)——避免全易题导致区分度低
- 尽量选**当时有争议**的案例(分歧越大,越能测出系统分析能力)
