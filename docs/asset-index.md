## 四、引擎访问路径（打通方式）

**TRIO 引擎（OS）通过以下路径访问沉淀**：

```bash
# 方法论分支 → /mnt/d/Agent文件/TRIO-{分支}/
# 项目数据   → /mnt/d/工作/项目/{项目}/
# 对标资产   → /mnt/d/工作/对标库/{company|person|industry|tech}-benchmark/
# 知识资产   → /mnt/d/工作/知识库/
```

**打通规则**（2026-08-11）：
1. **分析型任务** → 引擎自动查对应分支方法论（Agent文件）+ 项目历史（工作/项目）
2. **run 产物** → 落库 D:\工作\项目\{项目}\（不是 OS runs/）
3. **数码宝贝** → 读 run-history + decision-log（OS 状态）+ 项目活跃度（工作/项目）
