# TRIO 显式延期清单 v1.0

> 以下项目经过评估，**主动决定暂不做**。这不是遗漏——是显式选择。
> 每个项目标注了不做理由和重新评估触发条件。

| 项目 | 不做理由 | 重新评估触发条件 |
|------|---------|----------------|
| Neo4j 备份与灾备 | 单人单机·D盘故障概率低·neo4j-admin dump 可手动执行 | 图谱节点 >1000 或引入第二人操作 |
| Mermaid→PNG/SVG PDF嵌入 | mermaid-cli 需 Node.js 环境·当前管道不引入新依赖 | 报告读者明确反馈「PDF缺少图不可接受」 |
| API 调用成本监控 | 当前月度花费在可接受范围·未超预算 | 月度 API 费用 >$50 或引入付费模型 |
| 全自动实体消歧 | LLM 消歧误判率在当前规模下不可接受·人工裁决更安全 | 图谱节点 >500 且每日 staging 候选 >20 条 |
| Docker 容器化 | 单人 Windows+WSL2 环境·容器化 ROI 为负 | 第二人加入运营或需要跨平台部署 |
| Stock 门禁脚本 | Stock 当前产出量低·人工检查覆盖 | Stock 月产出 >10 份报告 |
| 文件路由自动化 (watchdog) | 实现成本 > 当前放错频率的损失 | 连续 3 次放错导致下游故障 |
| 系统运行仪表盘 | 手动查日志当前够用 | 决策回溯需求 >1 次/周 |
| Obsidian vault 移出生产路径 | vault 当前是分析辅助工具·不是生产组件 | vault 内容被引用为正式分析证据 |
