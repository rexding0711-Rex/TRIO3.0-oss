# TRIO IQ 提升路线图 v1.0

> 产出：2026-07-14 三视角自评 + 决策
> 基线：有效智商 118-125（比裸 LLM +10~20，比专业团队 -15~25）
> 目标：6 个月内拉到 130-135

---

## 一、自评结论（三视角共识）

| 维度 | 评分 | 说明 |
|------|------|------|
| 架构设计 | 135 | 认知隔离 + 门禁自进化 + 拓扑推演，领先同类 1-2 年 |
| 工程实现 | 105 | Shell 脚本 + JSON 配置 + 手动文件管理 |
| **有效输出** | **120** | 架构优势被原始实现拖累 |

**三大瓶颈**（按影响排序）：
1. **记忆系统**：每次会话重新加载一切，无自动上下文延续
2. **静态门禁**：正则 + 退出码，无量化指标
3. **零自主行动**：完全依赖人类启动，无 agent 循环

---

## 三、度量基线

| 指标 | 当前 | Phase 2 目标 | Phase 4 目标 |
|------|------|------------|------------|
| 反证覆盖率 | ~70%（估算） | ≥85% 自动检查 | ≥90% |
| 跨会话上下文保留 | ~10%（全靠手动文件） | ~60%（自动注入） | ~90% |
| 门禁误报率 | 未知 | < 5% | < 2% |
| 假设回测准确率 | 未追踪 | 建立基线 | ≥ 65% |

---

## 四、不变红线

- **不追求全自动**：TRIO 的价值在深度判断，不是速度。人工决策节点保留。
- **不换底层模型**：Phase 4 是远期愿景，当前瓶颈不在模型能力在系统架构。
- **不牺牲可解释性**：门禁规则必须可读可改，不能变成黑盒神经网络。
