# TRIO：一个盲区照明系统

> 版本：v1.0 · 2026-07-25 · 发送给 GPT / Gemini / Grok / Qwen 等外部模型评审

---

## 我们在做什么

TRIO 是一个**盲区照明系统**。它的核心命题是：

**人在跨越身份边界时，盲区是结构性的——不是知识不够，是视角不重叠。**

一个工程师看不懂投资条款，一个投资者读不懂热阻曲线。他们不是不聪明——他们站在不同的坐标系里。传统解决方案是"让不同的人对话"。TRIO 尝试的是另一条路：**让同一个人可以结构化地调用多个视角，并且知道每个视角看不到什么。**

这不是"AI 助手"。这不是"知识库"。这不是"分析引擎"——虽然它做分析。它的核心功能不是生成答案，是**在答案成形之前，暴露不同视角之间的信号不对称**。

---

## 它怎么工作

三个机制组成核心：

**1. 认知隔离（防群体思维）**：三个认知面具（发散者 Kimi / 审计者 DeepSeek / 工程交付者 Claude）并行处理同一份原始材料，互不可见对方输出。DeepSeek 使用独立 API 权重，提供真正的独立审计。

**2. 结构化怀疑（防自欺）**：每个关键结论附带可证伪条件。少数派视角不被多数投票淹没。矛盾不取平均——差异被保留、结构化、标注来源。

**3. 自验证闭环（防随机质量）**：交付前自检 → 自行修正 → 再检。外部抽查而非逐条重复。

在这之上，**Branch**（Stock / Investor / Engineer）是领域特定的认知插件。戴上 Stock 看资本市场，戴上 Engineer 看物理约束。摘下一个，就失去那个维度的视野。Branch 之间可以直接互借方法论——工程失效模式分析可以帮投资尽调识别技术风险，资本估值逻辑可以帮工程师理解规模化杠杆。

Branch 的实践教训会**上浮**到核心规则（CORE.md），经季度修订后所有 Branch 自动继承。这是双向流动：核心提供方法，Branch 提供经验验证。

---

## 为什么建这个

创始人 Rex 的核心动机：

> "人在跨身份体系的时候永远会有盲区。调研 MEMS 项目时必须深度研究红外特征和多光谱，否则就是低效甚至无效沟通。陶瓷 3D 打印项目也是——只知道大概不够。工程师不懂资本市场会错过杠杆。我只是不希望有盲区而已。"

这不是"追求全知"——那是进攻性的、以自我为中心的。这是"不希望有盲区"——防御性的、以对话质量为重心的。TRIO 的目标不是一个更聪明的人，而是一个**在任何跨域对话中不犯低级错误**的人。

## 已知局限（诚实的部分）

1. **情感型盲区**：TRIO 的面具都在同一个人的大脑里运行。如果你爱上一个项目，三个面具都会感受到——认知隔离隔离不了情感。

2. **伪多元确认风险**：Kimi 和 Claude 共享底层模型权重。2:1 的"共识"可能只是同源噪声。

3. **TRIO 自身的盲区**：目前没有自动化的自我盲区扫描。靠的是手动把设计文档发给外部模型评审——就像你现在读到这份文档的原因。

4. **未经对照实验**：单人多面具 vs 多人跨域协作——哪个找盲区更有效？没测过。TRIO 的假设是"一个人+外骨骼"在某些场景下比"多人协调"更快、更持续、更可追溯。但这只是假设。

## 我们想问你的

1. 这个"盲区照明"的命题本身——在你的视角里，有没有被过度浪漫化？
2. 有哪些盲区类型是我们完全没有覆盖到的？
3. 单人多视角系统最大的结构性风险是什么？（不是"可能出错"——是"如果不刻意防止，一定会出错"的那个东西）
4. 如果这是你的系统，你会砍掉什么？会加什么？
