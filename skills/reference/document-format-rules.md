# 文档格式规则

> ⛔ **本文件为阻断性门禁，不是参考建议。** 违反任一条 → 🛑 阻断交付。从 CLAUDE.md 提取，减少 context load。生成/编辑文档时按需加载。

## 排版保护铁律（L0 — 处理已有文档）

处理任何**已有**文档（docx/pptx/pdf）时：
1. **只做用户明确要求的操作**
2. 看到排版不一致、字体不统一、间距不对齐、样式不规范 → **先报告，禁止自动修复**
3. 用户说"修改内容"≠"修改排版"——改一个字就只改那一个字，别动格式
4. **违反此条 = 越界**

## 文档生成铁律（L1 — 生成新文档）

生成任何**新**含中文的文档（PPTX/Word/PDF）时：

### CJK 字体
1. **禁止**对中文文本使用 `Arial`、`Calibri`、`Helvetica`、`Times New Roman` 等拉丁字体
2. **必须**使用 `Microsoft YaHei`（微软雅黑）或 `Noto Sans CJK SC` 作为中文字体
3. **必须**在生成后运行 `/mnt/d/TRIO 3.0/scripts/check-cjk-fonts.py --strict` 校验
4. PPTX 脚本**必须**引用 `/mnt/d/TRIO 3.0/scripts/pptx-blueprint.js` 模板中的 `FONT` 常量

### PDF 导出
5. PDF 导出**必须**走 `/mnt/d/TRIO 3.0/scripts/deliver.sh <报告.md> --theme <A/B/C>`（一键三件套：MD+PDF+HTML）
   - 脚本内置 `--theme` 强制阻断：不带 `--theme` → 自动列出 A/B/C 三个视觉方案 → exit 1
   - 先让用户选 → 再执行。**禁止跳过**
   - 三种主题定义在 `config/pdf-themes.json`

### 报告内容
7. **只要最终报告**——报告中**禁止**出现：版本号、修正记录、变更日志、"之前认为…修正为…"、与旧版本对比。报告必须是独立完整的最终成品

### AI 过程痕迹禁止
8. 交付物（MD/HTML/PDF/PPTX）中**绝对禁止**以下 AI 过程痕迹：
   - ❌ 标题含版本标记：`（重做版）` `（审计后：XXX）` `（修订版）` `v2`
   - ❌ 章节标题含过程注释：`（审计后：XXX）` `（与上一版一致，略）`
   - ❌ 自指陈述：`这是审计前漏掉的` `感谢DeepSeek审计` `这次审计发现`
   - ❌ 版本对比表、章节占位符、致谢/道歉
   - ✅ 报告应该是**独立完整的最终成品**。读者不需要知道这是第几版

### PPTX 生成
9. **PPTX 生成前必须先列大纲**——每页标题 + 一句话内容，等用户确认增/删/改后再动手。**禁止**跳过确认直接生成

### 冗余词汇扫描
10. PDF/HTML 交付前，全文扫描并删除以下冗余字眼：
    `以下为` `如下` `值得注意的是` `需要指出的是` `显而易见` `毋庸置疑` `众所周知` `不难发现` `可以看出` `XX 展开` `XX 详见` `我们来看看`
    括号注释（如 `（topology-state.json 自动生成）`）→ 删除，标题干净。
