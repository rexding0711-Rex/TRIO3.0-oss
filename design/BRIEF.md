- **参考**: 有没有想要模仿的某份报告/某家公司风格？(URL 或描述)

## 代码生成约束

基于以上选择，Claude 生成代码时会：
1. 从 `themes/` 加载对应配色 JSON
2. 严格限制颜色数量 ≤ 8 个
3. 使用 `pages/` 中的页类型模板
4. 生成后运行 `check-cjk-fonts.py --strict`
