# 尾页模板

## 布局
```
┌──────────────────────────────┐
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │ ← 顶部强调线
│                              │
│        Thank You             │ ← 英文 (48pt, bold, white)
│                              │
│  ──────────                  │ ← 金色装饰线
│                              │
│  CRX · CeramX                │ ← 品牌名 + 一句话描述 (16pt, muted)
│  从天使轮到 IPO 的全路径战略   │
│                              │
│  雷克斯                       │ ← 团队署名 (13pt, muted)
│  Bruce | 材料与工艺负责人      │
│                              │
│  企业战略发展白皮书 | 2026.6   │ ← 文档信息
│  机密 | Version 1.0           │
└──────────────────────────────┘
```

## 关键参数
- 背景: 主题 dark 色
- 装饰线: 金色, w=2.5
