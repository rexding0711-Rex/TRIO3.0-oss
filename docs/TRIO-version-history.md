## 版本号规则

| 触发条件 | 升级动作 | 版本号变化 |
|---------|---------|-----------|
| 每次重大 run 完成 | 记录偏差，不升级 | 日志级 |
| 每次失败后提取新规则 | 新增一条 If-Then | **小版本 +1**（如 3.0→3.1） |
| 每次成功后发现可复制模式 | 固化成功模式为新协议 | **小版本 +1** |
| 新增一个方法论/场景 | 知识库扩展 | **中版本 +1**（如 3.x→4.0） |
| 参考输入发生范式级改变 | 系统重构 | **大版本 +1**（如 3→4） |
