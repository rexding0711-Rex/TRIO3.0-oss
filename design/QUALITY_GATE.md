# TRIO Artifact Quality Gate

> 每次 HTML/PDF/DOCX 交付前，逐项过。全部 ✅ 才能输出。
> 吸收来源: Claude Code 文档生成最佳实践（多源交叉验证）

---

## G0: 内容正确性（阻断）

- [ ] 所有数据可追溯到源文件或搜索结果
- [ ] 无 AI 痕迹词（审计/修正/v2/感谢XX/本轮/之前漏了）
- [ ] 标题层级无跳级
- [ ] 表格列数一致，无断裂行
- [ ] 中英文/数字间有空格

## G1: 视觉层级（阻断）

- [ ] 删除所有颜色后，信息层级是否仍然清晰？
- [ ] 关键数据是否"一眼可见"（不是藏在段落里）？
- [ ] 是否存在三个以上视觉元素在争夺注意力？
- [ ] 标题/正文/辅助文字的尺寸比例是否 ≥ 2:1.5:1？

## G2: 排版（阻断）

- [ ] 无孤行/寡行（orphan/widow）——标题下至少有 2 行正文
- [ ] 无文字溢出（overflow hidden 导致截断）
- [ ] 无空白页
- [ ] 分页处表格/代码块不被截断（page-break-inside: avoid）
- [ ] CJK 字体已嵌入或回退链完整

## G3: 反模板检查（阻断）

这是最容易被跳过的——AI 生成的"漂亮"往往是训练数据平均值。

- [ ] 删除品牌名称后，设计是否仍有辨识度？
- [ ] 删除所有渐变后，设计是否仍然成立？
- [ ] 是否存在仅装饰、无信息功能的元素？→ 若有，删掉
- [ ] 是否使用了默认卡片圆角（8px/12px）且无理由？
- [ ] 如果这是一本杂志封面，它会不会显得廉价？
- [ ] 哪三个地方最像"互联网模板"？→ 至少改一处

## G4: 格式专项

### HTML
- [ ] 单文件自包含（或明确标注外部依赖）
- [ ] 移动端响应式（320px 不崩）
- [ ] 打印样式（@media print）已定义
- [ ] 暗色模式（如果设计系统支持）

### PDF
- [ ] 分页意图明确（每页有 PAGE INTENT）
- [ ] 页眉/页脚完整（Logo + 页码 + 日期）
- [ ] 字体嵌入（CJK 不乱码）
- [ ] 文件大小 < 16MB

### DOCX
- [ ] 使用样式（Heading 1/2/3），不是手动调字体
- [ ] 目录可自动更新（TOC 字段）
- [ ] 页眉页脚完整
- [ ] 表格使用三线表或斑马纹

## G5: 最终检查

- [ ] 用一句话说清这份文档的"视觉概念"是什么
- [ ] 删掉至少一个"看起来酷但没用"的元素
- [ ] 在目标设备上打开确认过（浏览器/Word/PDF 阅读器）
