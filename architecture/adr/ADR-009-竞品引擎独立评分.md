# ADR-009: 竞品引擎独立评分维度
- 日期: 2026-07-10
- 状态: 试行
- 背景: 第十轮Claude审计指出——竞品引擎评分沿用人才引擎六维度(流动/技能/热度/接触)，其中"接触"对竞品分析无意义。评分标准与引擎领域不匹配
- 决策: 竞品引擎独立评分五维度——信号覆盖率0.30/逻辑链完整度0.25/可操作性0.20/反证质量0.15/时效性0.10
- 权重来源: 专家判断(Claude独立实例·第十一轮审计)
- 标注: 待25+ engine runs后用线性回归反校准。当前10次样本不足(每个自变量需≥5样本)
- 后果: 竞品引擎评分将不同于人才引擎。ADR-009权重写入competitive-intel-engine.json的L5评分段
