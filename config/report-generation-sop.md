# TRIO 对标报告生成 SOP v1.1

**更新日期**: 2026-07-03
**用途**: 每次生成竞品/模型/行业对标报告时，严格按此流程执行
**来源**: Fable 5 对比报告审计修正 + GPT 5.5 报告应用

---

## 阶段 0：启动门禁（3 分钟）

| 步骤 | 执行人 | 检查项 |
|------|:---:|------|
| 0.1 | Claude | 确认交付目标：报告主题、竞品名称、受众、格式 (PDF) |
| 0.2 | Claude | 确认交付路径：`D:\工作\TRIO\Reports\<报告名>-<日期>.md` |
| 0.3 | DeepSeek | `date +%Y-%m-%d` 确认当前日期。标记所有"瞬时状态"类数据需 ≤3 天 |
| 0.4 | Kimi | 一句话描述报告核心叙事方向 |

---

## 阶段 1：数据搜集（10 分钟）

**搜索模板（3-4 个并行搜索）**：
- `<竞品> current status <当月> 2026 pricing availability`
- `<我方> vs <竞品> benchmark comparison <关键基准> <当月> 2026`
- `<竞品> user feedback performance issues <当月> 2026`
- `<竞品> latest news <当月> 2026`（如竞品有已知重大事件）

**数据记录要求**：每条搜索结果必须记录来源名称 + 发布日期。

---

## 阶段 2：数据审计（10 分钟）

**使用审计框架** `deepseek-audit-framework.md`。

| 维度 | 致命错误示例 |
|------|------|
| 0. 时间戳 | 瞬时状态数据 >3 天未刷新 |
| 1. 数值精度 | 自报数据 vs 实测数据未区分；基准名称张冠李戴 |
| 2. 来源可信度 | 官方自报标 [5] 但应标 [3] |
| 3. 逻辑一致性 | 结论挑选数据而非数据推出结论 |
| 4. 完整性 | 只列我方赢的基准；争议数据不标 [2] |

**审计输出**：🔴 致命 / 🟠 重大 / 🟡 逻辑漏洞 / 🟢 可优化

---

## 阶段 2.5：信源独立性宣誓（2026-07-31 新增 · R7信源循环污染）

**在审计完成后、叙事构建前，强制输出以下声明**：

```
📋 信源独立性声明:
  本次分析使用的独立信源: [N] 个
  信源清单:
    · [信源1] — [等级: S/A/B/C] — [是否原始数据生产者]
    · [信源2] — [等级: S/A/B/C]
    · ...
  
  ⚠️ 可能共享上游的信源组:
    · [信源A] 和 [信源B] 可能引用同一上游 [上游名称] → 实际独立信源数 = N-1
    (如无此情况 → 标注"未检测到共享上游")
  
  信源等级分布: S:[] A:[] B:[] C:[] D:[]
  ⚠️ C级占比: [X]% (≥30% → 警告)
```

**硬规则**：
- 信源总数 < 3 → 标注「信源不足——分析结论置信度降级」
- 有 D 级信源出现在论据中 → 移除或降级为参考注释
- 多个信源指向同一上游 → 标注实际独立信源数

---

## 阶段 3：叙事构建（5 分钟）

| 检查项 | 方法 |
|------|------|
| 结论是数据推出的？ | 问：如果数据反过来，结论会不会变？ |
| 正反证据都呈现了？ | 强制列出 ≥3 个我方输的 + ≥3 个我方赢的维度 |
| 每个"碾压/领先"有数字？ | 无数字 → 删掉形容词 |

---

## 阶段 4：报告撰写（15 分钟）

**报告结构（固定模板）**：
1. 执行摘要（≤5 句，独立可读）
2. 模型能力对比（表格 + 脚注 + 置信度）
3. 成本效率对比（如适用）
4. 行为模式/工程纪律对比（如适用）
5. 竞品可用性警告（如有已知问题）
6. 优势与劣势总览
7. 建议
8. 数据溯源（来源 + 日期 + 置信度，逐条列出）

**硬性规则**：
- **禁止**在报告中出现：版本号、修正记录、变更日志、"之前认为…修正为…"、与旧版本对比
- 报告必须是独立完整的最终成品
- 每个关键声明标注置信度 [1-5]
- 争议数据标 [2]

---

## 阶段 5：格式交付（5 分钟）

| 步骤 | 执行人 | 检查项 |
|------|:---:|------|
| 5.1 | Claude | PDF 纯黑白高反差（#000/#fff），Noto Serif CJK SC 字体 |
| 5.2 | Claude | 生成 PDF |
| 5.3 | Claude | 确认文件路径 `D:\工作\TRIO\Reports\` |
| 5.4 | DeepSeek | 最终确认：PDF 内容与 MD 一致 |

---

## 反模式（禁止）

- ❌ 报告里写版本号和变更日志（用户只要最终报告）
- ❌ 把 Multilingual 当 Pro（76.2% ≠ 55.4%）
- ❌ 瞬时状态数据不按当天日期重搜
- ❌ 自报 benchmark 当实测用（标 [3] 不是 [5]）
- ❌ 只列赢的、藏输的
- ❌ PDF 用彩色低反差配色
- ❌ 跳过 DeepSeek 终审直接交付
