# TRIO 操作系统 v1.0 速查卡

> 2026-07-22 · 一页纸 · 可打印贴在墙上

---

## 一句话定义

**TRIO 是把"原始信息"转化为"可执行决策"的 AI 操作系统，由基础设施层（Infra）和业务五环（Flow）双层驱动。**

---

## Infra 层（基础设施 · 四个模块）

| 模块 | 一句话 |
|------|--------|
| **准确度** | 拓扑推演 + 反事实验证，确保分析结论经得起"如果当初不一样呢"的拷问 |
| **隐私** | 认知隔离——三面具共享基础设施，但信息边界不穿透 |
| **安全** | 不可逆操作硬约束（禁止 force push、禁止裸删对标库、禁止绕过 deliver.sh） |
| **记忆** | 会话状态持久化 + 训练日志落库 + 季度修剪防 token 膨胀 |

---

## 业务层（五环流水线）

```
一手信息 → 载体 → 人 → 增量 → 决策
```

| 环 | 定义 | 一句话 |
|----|------|--------|
| **一手信息** | 未加工的原始信息 | 输入的起点——未经他人解读、标注、摘要的事实或数据 |
| **载体** | 三面具 + 拓扑推演 + 硬件 | 分析引擎——Claude（交付）、Kimi（洞察）、DeepSeek（审计）协同拓扑推演 |
| **人** | 最终裁判 | Rex 是唯一决策权持有者——AI 提供选项和推演，人不授权给机器 |
| **增量** | 认知复利 | 每次分析沉淀为对标库、训练日志、方法论——下次起点更高 |
| **决策** | 唯一交付物 | 五环的终点——所有分析最终服务于一个可执行的判断 |

```
增量     ████░░░░░░ 35%  训练日志有，自动关联/检索弱
决策     ███░░░░░░░ 30%  格式管道有，决策质量评估缺
```

**下一步修复优先级：增量环（35% → 50%）** —— 认知复利是五环的护城河，当前最拖后腿。
