# TRIO 3.1 五维评分卡 v1

> 版本：v1.0
> 日期：2026-07-15
> 栈：Claude Code CLI（编排）+ DeepSeek V4 Pro API（推理）
> 用途：W1 评估基线 / 门禁语义层 / Calibration 输入

---

## 评分架构

```
评估 = 机械层（确定性，$0） + 逻辑层（LLM Judge，$<0.001/次） + 结构层（规则，$0）
```

| 层级 | 检测内容 | 成本 | 可靠性 |
|------|---------|------|--------|
| 机械层 | 数字一致性、引用存在性、日期先后、预测格式完整性 | $0 | 100%（确定性） |
| 逻辑层 | 因果链、证据匹配度、反例覆盖 | ~$0.001 | 75-85%（需 rubric 约束） |
| 结构层 | 章节完整性、置信度标注、时间窗口 | $0 | 100%（确定性） |

**核心原则**：DeepSeek 同时是生成模型和评估模型 → 评估必须尽可能依赖机械层和外部数据，LLM Judge 只用于语义判断。不要让 LLM 评"报告写得好不好"，让它评"报告犯了什么错"。

## 五维定义

### F1：事实准确性 | 机械 70% + 外部数据 30%

**核心问题**：报告声称的事实是否与可验证数据一致？

| 分数 | 标准 | 检测方式 |
|------|------|---------|
| 5 | 所有关键数据（营收/利润/日期/事件）与公开来源一致，零偏差 | 机械比对 |
| 4 | ≤1 处次要数据偏差（如四舍五入差异），关键数据正确 | 机械比对 |
| 3 | 1-2 处偏差，但不影响核心结论 | 机械比对 |
| 2 | ≥3 处偏差，或 1 处关键数据错误影响结论 | 机械比对 |
| 1 | 核心论据建立在错误事实之上 | 机械比对 |

**A 股特化检测点**：
- 营收/净利润数字 vs 年报/季报原文
- 股价/市值数据 vs 交易日实际数据
- 高管变动/公告日期 vs 公司公告时间线
- 行业数据年份 vs 数据发布时间

**机械层实现**：
```
1. 提取报告中所有带数字的句子
2. 正则匹配 [数字] + [单位：亿/万/元/%/股]
3. 在原始材料中搜索相同数字 → 匹配 = 通过，不匹配 = 标记
4. 统计：匹配数 / 总数 = 事实密度
```

### F2：因果完整性 | LLM Judge 100%

**核心问题**：从证据到结论的推导链是否完整，有无逻辑跳跃？

| 分数 | 标准 |
|------|------|
| 5 | 每一步推理有明确前置条件，A→B→C 链条完整，标注了中间变量 |
| 4 | 主链完整，1-2 处次要推理可补充但已有隐含机制说明 |
| 3 | 1-2 处逻辑跳跃（如从宏观直接到个股，缺中间层） |
| 2 | 3-5 处跳跃，多处"因为 A 所以 B"缺少机制解释 |
| 1 | 核心结论与证据之间无逻辑连接，或强加因果（E03） |

**LLM Judge Prompt**：
```
你是逻辑审计员。请检查以下分析报告的因果链完整性。

评分标准：
5 = 每一步推理都有明确的前置条件和中间变量，链条完整
3 = 存在 1-2 处逻辑跳跃（如从行业趋势直接跳到个股结论，缺中间传导）
1 = 核心结论与证据之间无逻辑连接

A 股常见逻辑跳跃示例（必须标记）：
- "行业景气 → 个股受益"（缺：市占率/产能/客户结构）
- "政策利好 → 股价上涨"（缺：利好程度量化/受益标的筛选/时间窗口）
- "海外对标涨了 → A 股也会涨"（缺：市场结构差异/资金面/估值锚）

报告文本：
{text}

只输出一个 1-5 的整数，不要解释。
```

### F3：证据匹配度 | 机械 50% + LLM Judge 50%

**核心问题**：引用的证据是否真的支持结论？（不是"有没有引用"，是"引用对不对口"）

| 分数 | 标准 | 检测方式 |
|------|------|---------|
| 5 | 每个关键论断有 ≥2 个对口证据，证据与结论直接相关 | 引用计数 + LLM |
| 4 | 多数论断有对口证据，1-2 个论断证据偏弱 | 引用计数 + LLM |
| 3 | 有引用但部分"文不对题"——引了数字但数字不支持该结论 | LLM Judge |
| 2 | 半数以上论断无对口证据，或证据与结论明显不匹配 | LLM Judge |
| 1 | 通篇断言无锚，或引用内容与结论矛盾 | LLM Judge |

**注意**：F3 替代了原方案中的"证据充分性（引用密度）"。50 个不相关的引用不如 1 个精准引用。

**机械层**：统计 `[来源:xxx]` 或 `（年报P23）` 格式的引用标记数量。

**LLM Judge Prompt**：
```
你是证据审计员。对以下报告中的每个关键论断，判断其引用的证据是否真的支持该结论。

关键论断 = 包含"因此/表明/意味着/预计/判断"的句子

评分标准：
5 = 所有关键论断的证据对口且充分
3 = 部分引用的证据与结论关联弱（"文不对题"）
1 = 多数论断无证据支撑，或引用的证据实际上不支持/矛盾于结论

报告文本：
{text}

只输出 1-5 的整数。
```

### F4：反例覆盖度 | LLM Judge 100%

**核心问题**：是否真正提出了一个可能推翻主结论的替代解释？

| 分数 | 标准 |
|------|------|
| 5 | 明确列出 ≥2 个反对论点，并逐一用证据回应 |
| 4 | 列出 1-2 个反对论点，有简要回应 |
| 3 | 提到了风险但流于形式（复制粘贴通用风险提示） |
| 2 | 仅在末尾简单提及"风险提示"，无实质讨论 |
| 1 | 完全未考虑反对意见，单向看多/看空（E05） |

**注意**：F4 不是检查"有没有写风险提示章节"，而是检查"是否真正提出了能推翻主结论的替代解释"。

**LLM Judge Prompt**：
```
你是批判性思维审计员。请评估以下报告是否真正考虑了反对意见。

评分标准：
5 = 至少提出 2 个具体的、可能推翻主结论的替代解释，并用证据逐一回应
3 = 提到了风险但流于形式（通用"宏观经济风险"等套话），未针对核心逻辑
1 = 完全单向论证，未考虑任何反例

注意：不要因为报告有"风险提示"章节就给高分。检查那些风险是否真的能推翻报告的核心结论。

报告文本：
{text}

只输出 1-5 的整数。
```

### F5：可验证性 | 机械 60% + LLM 40%

**核心问题**：结论是否包含明确的观测点、量化指标和时间窗口？（这是 Calibration 的前提）

| 分数 | 标准 | 检测方式 |
|------|------|---------|
| 5 | ≥3 个结论含：具体指标 + 阈值 + 时间窗口（如"Q3 毛利率 > 30%，2026-10-31 前验证"） | 机械 |
| 4 | ≥2 个含完整验证三要素 | 机械 |
| 3 | ≥1 个含完整三要素，其余为定性判断 | 机械 |
| 2 | 有预测但缺量化边界（如"下季度会变好"——好多少？） | 机械 + LLM |
| 1 | 全篇定性描述，无任何可证伪的观测点（E09） | 机械 + LLM |

**机械层检测**：
```
完整验证三要素 = metric + threshold + deadline

正则模式：
- metric: 营收|净利润|毛利率|ROE|股价|市值|订单|产能|市占率|增速
- threshold: >|>=|<|<=|突破|达到|超过\s*[\d.]+
- deadline: \d{4}年[第]?[一二三四季度]|Q[1-4]\s*\d{4}|未来\s*\d+\s*(个月|周)|截至\s*\d{4}

统计：同时包含三要素的结论数量
```

## 可重复性验证

W1 必须执行：抽 3 份报告，每份重复评分 3 次。

```
如果 std(total_score) > 1.5 → rubric 不够清晰 → 修订后重测
如果 std(total_score) ≤ 1.5 → rubric 可重复 → 进入基线建设
```
