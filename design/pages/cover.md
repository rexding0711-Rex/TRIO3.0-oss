# 封面模板

## 布局
```
┌──────────────────────────────┐
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │ ← 顶部强调线 (主色, h=0.04)
│                              │
│ 雷克斯                        │ ← 作者名 (12pt, muted)
│ 2026年6月                     │ ← 日期 (10pt, muted)
│                              │
│         CRX · CeramX         │ ← 英文品牌名 (46pt, bold)
│       企业战略发展白皮书       │ ← 中文标题 (30pt, 主色)
│                              │
│  ──────────                  │ ← 金色装饰线 (w=2.5)
│                              │
│  副标题（两行）               │ ← 15pt, muted
│                              │
│                   机密|V1.0   │ ← 右下标签 (9pt)
└──────────────────────────────┘
```

## 关键参数
- 背景: 主题 dark 色
- 字体层级: 46 → 30 → 15 → 12 → 10
- 装饰线宽度: 2.5 inches
- 颜色使用: 主色(标题) + 金色(装饰线) + muted(其余)
