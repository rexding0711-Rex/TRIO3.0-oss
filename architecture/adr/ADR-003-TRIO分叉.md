# @layer: evolution
# ADR-003: TRIO 分叉——基础版 vs 3.14(π)

## 状态

提案 | 2026-06-26

## 背景

TRIO 3.0 当前只有一个版本——Rex 自己用的完整系统。但 Rex 有两个不同需求：

1. **给朋友用**——让朋友体验三面具协作，同时记录他们的操作习惯和思维方式
2. **给自己用**——TRIO 3.14(π)，探索系统完美的极限

两者结构不同，需要分叉。

## 决策

### TRIO 基础版（朋友版）

**定位**：横向吸收——采集不同人的工作流和思维方式。轻量、可分享、零门槛。

**核心区别**：
- 去掉日进化引擎（朋友不需要）
- 去掉能力栈、ADR、知识库（太复杂）
- 保留三个面具的简化版：Kimi 搜索 + DeepSeek 核查 + Claude 综合
- **🆕 思维记录器**：每次交互自动记录用户的操作习惯和思维方式，生成 `user-profile.md`

**思维记录器的设计**：
```
每次SessionEnd:
  - 记录用户问了什么类型的问题（分类/搜索/分析/决策）
  - 记录用户的表达风格（简洁型/详细型/质疑型）
  - 记录用户的决策偏好（数据驱动/直觉驱动/他人意见驱动）
  - 记录用户的知识盲区（哪些概念被反复询问）

累积生成 user-profile.md:
  - 工作思维模式画像
  - 核心关注领域
  - 决策风格
  - 认知偏好
  - 盲区与成长建议
```

**传输机制**：用户手动导出 `user-profile.md` → 发给 Rex → Rex 用 TRIO 3.14 分析

### TRIO 3.14 (π)

**定位**：纵向深入——在某一板块上探索极限深度。π = 无穷，永远往深走。

**核心区别**：
- 保留全部 TRIO 3.0 功能 + 本书全部学习成果
- 六层架构硬化 + 禁区守卫 + 背压机制
- 54 项能力栈 + 4 条演化原则 + ADR 体系
- 日进化引擎持续运行
- π = 无穷探索，永远在变好

## 两个版本的关系

```
TRIO 基础版 ──→ user-profile.md ──→ TRIO 3.14(π)
  (朋友用)      (思维记录器输出)      (Rex分析朋友的思维)
```

基础版收集数据，3.14 分析数据。基础版是传感器，3.14 是分析引擎。

## 后果

- 基础版需要全新的目录结构，从 3.0 大幅精简
- 3.14 需要隔离朋友数据，不混入自己的知识库
- 思维记录器的隐私问题——必须让朋友知情同意
- 两个版本的维护成本——优先实现基础版的思维记录器

## 备注

《系统架构设计方法论》第 1 章：架构是社会契约。基础版是给朋友的契约——"我用 TRIO 帮你思考，同时向你学习"。
