# 章节分隔页模板

## 布局
```
┌──────────────────────────────┐
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │ ← 顶部强调线
│                              │
│  PART 01                     │ ← 英文编号 (13pt, 琥珀色, charSpacing:8)
│                              │
│  赛道全景                     │ ← 中文标题 (42pt, 白色, bold)
│                              │
│  数据中心液冷市场 · CRX可触达  │ ← 描述 (13pt, muted)
│  市场 · 市场时机窗口          │
│                              │
│  ──────────                  │ ← 金色装饰线 (w=2.5)
│                              │
│                         ░░░░ │ ← 右侧装饰区块 (w=2.8, transparency:40)
└──────────────────────────────┘
```

## 关键参数
- 背景: 主题 dark 色
- 右侧装饰: 矩形 w=2.8", h=5.625", navy+40%透明
- 底部: 细横线 (紫色, w=3.0, h=0.02)
