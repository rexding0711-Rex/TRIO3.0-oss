# handoff — 会话交接

将当前会话的核心状态压缩为一份交接文档，让下一个接手者（另一个面具、另一个会话、或另一个人）不需要重读全部历史就能继续。

> 偷师 Matt Pocock 的 handoff skill。TRIO 版增加了三面具之间的切换协议——每个面具输出自己视角的"我看到了什么、我卡在哪里、下一步是什么"。

## Steps

### Step 1: 提取当前状态

从会话中提取以下状态信息：

- **当前阶段**：triage 判定的 depth/type、当前在哪个 step、已完成哪些
- **关键发现**（≤5 条）：已确认的事实和判断
- **待解决**（≤5 条）：未关闭的 `???` 节点、未消解的矛盾、悬而未决的决策
- **当前阻塞**：为什么停在这里？需要什么才能继续？

**完成标准**：四个字段全部非空。

### Step 2: 三面具状态快照

如果当前会话涉及三面具协同，每个面具输出一句话：

```
Kimi 视角: [我看到了什么模式/叙事] — [我卡在哪里] — [下一步建议]
DeepSeek 视角: [我验证了什么/怀疑什么] — [我卡在哪里] — [下一步建议]
Claude 视角: [我做了什么/什么还没做] — [我卡在哪里] — [下一步建议]
```

**完成标准**：每个参与的面具都有状态快照。

### Step 3: 建议技能

列出下一个接手者应该首先加载的技能（≤3 个），按优先级排序。

**完成标准**：技能列表非空，每个技能名在 skills/ 目录中确实存在。

### Step 4: 写交接文档

将以上信息写入操作系统临时目录（不是当前 workspace）：

```
路径: /tmp/trio-handoff-{timestamp}.md
```

**不要复制的**（已经在其他制品中）：
- 完整的分析报告正文 → 引用路径
- Git diff / commit log → 引用 commit SHA
- 已发布到 issue tracker 的 issue → 引用 issue URL
- 原始搜索结果 → 引用 research-notes.md

**必须包含的**：
- 当前阶段 + 阻塞点
- ≤5 条关键发现
- ≤5 条待解决
- 三面具快照
- 建议技能列表

**安全**：删除任何敏感信息（API key、密码、个人身份信息）。

**完成标准**：交接文档已写入，路径已告知用户。

## 输出格式

```markdown
# TRIO 交接: <任务名> — <时间戳>

## 当前阶段
- 分析类型: <type>
- 深度: <depth>
- 当前 Step: <N>
- 已完成: <列表>
- 阻塞: <原因>

## 关键发现
1. <发现> [置信度 L]
...

## 待解决
1. ??? <缺口>
...

## 三面具快照
- Kimi: ...
- DeepSeek: ...
- Claude: ...

## 建议技能
1. /<skill-name> — <为什么>
...

## 相关文件
- 报告: <路径>
- 调研笔记: <路径>
- Git: <commit SHA 或 branch>
```

## 失败模式

| 模式 | 预防 |
|------|------|
| 交接文档 = 会话重放——太长 | Step 4 "不要复制的"清单——只写增量状态，不写全量历史 |
| 接手者不知道从哪开始 | Step 3 建议技能——给具体入口，不是泛泛的"继续分析" |
| 敏感信息泄露 | Step 4 安全——写入前扫一遍 |
| 三面具快照缺失——只有一个视角的交接 | Step 2 强制——每个参与的面具都写一句话 |
